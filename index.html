Capítulo 1 · Glosario

Seis palabras que todo programador usa

IDE

Es la “casa” completa del programador: un solo programa donde escribo el código, lo ejecuto, busco errores y organizo mis archivos. Sus siglas significan Entorno de Desarrollo Integrado.

Ej: Visual Studio, PyCharm

Concatenación

Es pegar dos o más textos para formar uno solo, como unir piezas de un rompecabezas. Escribe tu nombre:

"Hola, " + nombre → Hola, Brandon

Código fuente

Son las instrucciones originales que escribo en un lenguaje que yo puedo leer. Después la computadora las traduce a su propio idioma para ejecutarlas.

print("Hola mundo")

Plugin

Es un complemento que se instala en un programa para darle poderes extra, como ponerle colores al código o corregir mi ortografía mientras escribo.

Ej: un tema de colores para VS Code

Bug

Es un error escondido en el programa que hace que funcione mal o se detenga. Encontrarlo y arreglarlo se llama depurar.

print("Hola) # falta una comilla

Import

Es la orden para traer código que ya existe en otro archivo o librería y usarlo sin volver a escribirlo. Me ahorra trabajo.

import math
math.sqrt(16) # 4.0

Editor de texto vs. IDE

Editor de textoIDE
Ayuda al escribirCasi ninguna: solo escribes y guardas.Autocompleta, resalta y avisa de errores mientras escribes.
Ejecutar y depurarSe hace aparte, desde la terminal.Trae botón de ejecutar y depurador para cazar bugs paso a paso.
Manejo de proyectosTrabajas un archivo a la vez.Organiza carpetas, librerías y versiones en un solo lugar.
Peso y velocidadLiviano y rápido de abrir.Más pesado; necesita más memoria.
EjemplosBloc de notas, Notepad++Visual Studio, PyCharm, IntelliJ

Dato curioso: VS Code nació como editor, pero con plugins se comporta casi como un IDE.
